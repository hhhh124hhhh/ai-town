五 · 新旧皮肤对比：为什么 v2 才是对的

旧 panel_bg（v1 · 整图烘焙）

  • 头像框、名牌、按钮槽画死在背景里——布局锁死
  • 祥云角饰只有上两角，上重下轻
  • 9-slice 一拉伸：格子变椭圆、印章变形
  • 游戏里要靠 Wash() 半透明宣纸盖掉内侧装饰才能压字

新 panel_main（v2 · 拆层组件）

  • 内容区完全空白，布局由代码（排版规则）决定
  • 四边均匀+回纹角饰四角一致，9-slice 安全
  • 任意尺寸拉伸角饰不变形（见第二节实测）
  • 印章/云纹/分隔线独立成件，想放哪放哪
