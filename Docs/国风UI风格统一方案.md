# AI Town 国风UI风格统一方案

> 提交前紧急优化方案 | 2026-08-29
> 核心原则：3D游戏+2D UI是行业标准，关键是2D UI的视觉语言与3D世界观统一

---

## 一、整体风格定位

**国风手绘水墨风**——与3D低多边形国风小镇的世界观统一。
- 3D场景：低多边形渲染，平滑光照，国风建筑
- 2D UI：手绘水墨表现，宣纸质感，毛笔描边，国风装饰
- 维度不同但视觉语言同源（都是"中国风小镇"）

**参考作品**：《原神》UI（二次元3D+二次元2D）、《艾尔登法环》UI（哥特3D+哥特2D）

## 三、字体系统

| 用途 | 字体 | 字号 |

| 按钮文字 | 思源宋体 Bold | 16-18px |

## 四、部件样式规范

### 1. 面板（AI建筑生成/委托/图纸）
- 背景：宣纸色 `#F5EFE0`，90%透明度
- 边框：深棕色 `#8B4513`，2-3px，不规则手绘边缘
- 四角装饰：回纹/云纹（简单的线条装饰即可）
- 内边距：20px
- 标题：顶部居中，行书字体，深墨色

### 2. 主按钮（生成建筑/确认/接受委托）
- 填充：朱红色 `#A52A2A`
- 文字：宣纸色 `#F5EFE0`，思源宋体 Bold
- 描边：深棕色 `#8B4513`，2px
- hover：明度+10%（变亮）
- 点击：缩放0.95（凹陷感）+ 点击音效

### 3. 次按钮/标签（屋舍/公所/园景等）
- 未选中：宣纸色填充 + 深棕描边 + 深墨色文字
- 选中：朱红填充 + 白字 + 深棕描边
- hover：未选中时边框变朱红
- 尺寸：统一宽高，间距统一

### 4. 输入框
- 填充：宣纸色 `#F5EFE0`
- 描边：深棕色 `#8B4513`，2px
- 内边距：10px
- 占位符：棕色 `#6B5344`
- 聚焦：边框变朱红 `#A52A2A`

### 5. 顶部状态栏
- 背景：深墨色 `#1A1A1A`，80%透明度
- 描边：金色 `#DAA520`，1px
- 文字：白色/金色，思源宋体 Medium
- 图标：国风线描风格，金色/白色
- 布局：图标+文字横向排列，左右两个状态栏样式统一

### 6. 验收评级弹窗
- 背景：宣纸色 `#F5EFE0`
- 边框：S级=金色 `#DAA520`，A级=银色 `#C0C0C0`，B级=铜色 `#B87333`
- 评级大字：居中，巨大字号，对应颜色，带光芒效果
- 奖励明细：金币图标+大洋数值，星形图标+繁荣度数值
- 确认按钮：朱红色主按钮

## 五、反馈特效规范

### 1. AI生成中反馈
- 面板显示"生成中..."文字
- 简单旋转加载图标（国风旋转纹样）
- 锤子敲击音效循环（节奏与进度匹配）
- 可选：建筑白模预览（方块一块块拼起来）

### 2. 建筑生成完成反馈
- 建筑从地面缩放出现（0→1，0.5秒）
- 尘土粒子效果
- 金色光芒从建筑底部向上照射
- "生成成功"提示 + 完成音效

### 3. 验收评级反馈
- 评级弹窗出现动画（从中心缩放）
- S级：金色光芒粒子 + 欢呼音效
- A级：银色光芒 + 满意音效
- B/C级：普通提示 + 一般音效
- 奖励明细逐条出现

### 4. 奖励反馈
- 金币从建筑里飞散出来（3D金币粒子）
- 金币飞到顶部大洋计数
- 数字跳动动画 + "+50大洋"飘字从下往上飘
- 金币音效
- 繁荣度进度条增长 + "+10繁荣"飘字

### 5. 委托目标提示
- 接委托后，屏幕左侧出现宣纸色小面板
- 显示"当前委托：建一座XXX" + 目标图标
- 完成后打勾 + "叮"音效 + 面板消失
- 始终可见，不遮挡核心操作

## 八、核心原则总结

1. **3D+2D没问题**：行业标准，关键是视觉语言统一，不是维度统一
2. **质感统一是基础**：所有UI元素用同一种渲染方式（手绘水墨），不要渐变/纯白/无风格元素混入
3. **即时反馈是体验**：每个操作0.1秒内有回应，AI生成等待时间必须有反馈
4. **先跑通再打磨**：明天提交先保证流程闭环+基本反馈，质感优化提交后再做
