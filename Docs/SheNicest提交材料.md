## 项目说明（表单正文）

AI 小镇是一座"会记住你的民国小镇"：玩家第一人称漫游，用自然语言盖楼，接 NPC 委托赚大洋，把荒地建成传奇之城。

问题：文本生成 3D 建筑的演示不少，但都停在"网页面板里看模型"，没有玩法闭环。
方案：把 Luanti Builder 的自然语言→建筑能力迁到团结引擎（Unity 2022.3），包进完整游戏循环——
① 说句话就起楼：「建一座青砖老洋楼」秒级落地，门朝玩家、贴地不穿模、自动接路；
② NPC 有记忆：4 位民国 NPC（巡捕/茶馆掌柜/老板娘/账房）接入大模型，带人设短期记忆，聊过的话题下次接着聊；
③ 委托验收闭环：NPC 现场发单（LLM 生成话术）→ 绿圈划地 → 玩家建造 → 服务端判分（类型/方块数/占地/距离）→ 评级发奖 → 繁荣度升级解锁图纸；
④ 小镇会长大：繁荣度驱动等级（荒地聚落→传奇之城），树、路灯、牌坊随进度出现。
现场完成内容：可玩 Demo（含开场演出、27 种建筑模板、委托系统、黄昏光照）；Python 后端零依赖一键启动。
使用方式：双击 start_server.command 启动 AI 后端，进游戏按 E 对话、Tab 建造、C 查看委托。

## 二次开发计划（100-500 字，若申报二次开发）

本作品在原项目 Luanti Builder（自然语言→Luanti 方块建筑）基础上的新增与改造：
① 引擎迁移：从 Luanti/HTML 演示迁移至团结引擎（Unity 2022.3）第一人称 3D 场景，URP 黄昏光照、烘焙氛围；
② 游戏化：新增开场演出、NPC 委托系统（发单/绿圈/判分/评级/繁荣度等级/图纸解锁）、建筑放置手感（幽灵预览/重叠检测/落地引导）；
③ NPC 生命：接入大模型人设对话与短期记忆，规则回复兜底，离线可玩；
④ 建筑 JSON 通道升级：27 模板程序化生成 + StreamingAssets 同款直读，描述词驱动材质染色。
验证：全部 API 有自动化测试（32 断言全过），核心循环 Play 走查通过。
后续计划：NPC 自主游走、更多建筑类型、打包桌面 exe + 便携 Python 随包。
