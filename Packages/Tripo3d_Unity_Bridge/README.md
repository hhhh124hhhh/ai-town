# Tripo3D Unity Bridge

基于 WebSocket 的 Unity 编辑器插件，可直接从 Tripo3D 网页端接收并导入 3D 模型。

## 安装步骤

将插件安装到你的 Unity 工程中（Unity 2021.3 或更高版本）：

1. 打开 **Window > Package Manager**。
2. 点击 **+** → **Add package from disk...**。
3. 选择解压后的 `Tripo3d_Unity_Bridge` 文件夹中的 `package.json`。

导入完成后，打开 **Tools > Tripo3D Bridge**，点击 **Start Server** 即可开始接收模型。

## 教程

有关插件的安装教程和使用指南，请访问 **[Tripo 帮助中心](https://studio.tripo3d.com/help.html#api)**。
