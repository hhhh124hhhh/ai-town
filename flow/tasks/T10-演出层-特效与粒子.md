> 状态:代码完成待 Play 验收(2026-08-29:三 Must+两 Should 已接挂,编译零错,场景已落盘;观感/FPS 待用户 Play) · 优先级:P1(直接放大 3 个 Demo 高光时刻) · 里程碑:M4
> 前置:T08 委托循环(绿圈/交付)、CinematicIntro(建筑生长)、篝火道具(-6,-7)已就位;项目当前零粒子代码(grep 证实)。

## 目标
用粒子给三个"wow 时刻"补上最后一层反馈,让画面"活":建造有尘、交付有庆典、篝火有火;环境氛围点缀不做大。

## 素材策略(硬性路由)
**一律先 `search_effect_lib`**(1300+ 卡通风格成品粒子:爆炸/火焰/烟尘/彩带/confetti 等,免生成等待、即下即用),搜不到再用 generate_* 兜底。搜索关键词先英文(fire/campfire/dust puff/confetti celebration/sparkle),必要时换词重搜(offset 翻页)再放弃。下载即扣积分(默认 20/件),**先搜准再下,禁止试错式连下**。

## 步骤
1. search_effect_lib 三轮主搜(campfire fire / dust smoke puff / confetti celebration gold),选定后 download_effect 入 `Assets/Effects/`(zip 含依赖自动解包)。
2. URP 兼容体检:下载的材质若非 URP(Particle Standard Unlit 等 Built-in 着色器)会粉色——逐 prefab 查材质 shader,不兼容则换 URP/Particles/Unlit 或 URP/Unlit + 原贴图,色值/软边用粒子系统自带参数复原。
3. 挂接(全部运行时代码,不进场景文件):
   - `EffectsCatalog.cs`(静态):`Play(string key, Vector3 pos)` 统一入口,GameObject.Instantiate + 2.5s 自毁(循环型除外)。
   - BuildingManager:整建筑生成完毕回调播落尘(位置=建筑包围盒底部中心)。
   - CinematicIntro:生长阶段每完成 ~25% 播一次落尘;跳过时不播。
   - CommissionSystem:验收通过分支 + 升级分支调 `Play`(世界坐标=绿圈中心)。
   - 篝火/烟囱/萤火:Editor 菜单 `Tools→AI Town→Place Ambient FX`(幂等,参照 PropPlacer 模式,坐标写清单)。
4. 参数预算:同屏发射总数 ≤400,庆典类 burst ≤150/次;半径 >60m 的循环粒子加 Culling(或干脆不加,场景小)。
5. 验证:Play 走 T08 一单全程录三个触发点截图;Stats FPS ≥30。

## 验收标准
- [ ] 三 Must 全部在 Game 视图可见且时机正确(建造落尘/交付金色庆典/篝火常燃)
- [ ] 特效无粉色材质、无 URP 报错(Console 清零)
- [ ] 与 DrawFlash、开场演出不互抢(特效在 DrawFlash 弹入前 0.2s 内起)
- [ ] 全开时 FPS ≥30

## 已知边界/坑
- 特效挂在道具父级下会继承离谱 scale(旗 415x 判例)——粒子一律挂独立节点或 worldPositionStays。
- CinematicIntro 演出期禁用一堆组件,新增特效触发需检查相位(只在该播的相位播)。
- effect lib 是卡通风,与写实民国天空盒有画风差——选暖色低饱和款,拿不准先下 1 件对比再批量。
- 打包时 Effects 资源引用必须在场景/代码可达路径(不能只躺在 Editor 菜单里)。
