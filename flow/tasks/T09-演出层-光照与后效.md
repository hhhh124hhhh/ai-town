# T09 · 演出层:光照与 URP 后效

> 状态:未开工 · 优先级:P1(打包前最后一道视觉工序) · 里程碑:M4(自 T07 步骤 3 拆出)
> 前置:民国氛围菜单已跑过(暖阳光/雾/天空盒已就位);场景无任何 Volume(grep Main.unity 证实)。

## 目标
给民国小镇定一个"定妆光":黄昏暖阳 + Bloom 辉光 + SSAO 体积感,夜里路灯/篝火点亮可读性;全程不引入自定义 Shader(团结引擎 URP 14.2.0-t1 已知坑)。

## 现状盘点(2026-08-28 证实)
- Main.unity 无 Global Volume/后处理;模板自带 `Assets/Settings/VolumeProfiles/`(CinematicProfile/HighQualityVolumeProfile 等,urp-sample 来源,参数未必合本场景,需逐项核对或新建)。
- 平行光:Directional Light 已被 Minguo Atmosphere 调成暖色(1,0.94,0.84)×1.8,软阴影。
- 雾:Linear 25-110m 青灰 #BFC2C7;天空盒:Panoramic minguo_skybox。
- 可点光的现成锚点:主路 lightpost_single(若干,scale 2.053)、广场篝火(-6,-7)、骑楼发光招牌、井(6,-7)。

## 步骤
1. **Global Volume(Basic)**:场景建 `_Systems/GlobalVolume`,挂 Volume(Global)+ 新建 `Assets/Settings/VolumeProfiles/AiTownMinguoProfile.asset`,只开:Bloom(threshold ~1.1/intensity ~0.6)、SSAO(需确认 PC_High_Renderer 已挂 ScreenSpaceAmbientOcclusion RendererFeature,没有则加)、ColorAdjustments(暖色微降饱和 + 轻微 Vignette)。模板存量 Profile 若参数合适可复用,但必须在截图验证后决定。
2. **黄昏定妆(默认态)**:平行光角度压到 ~25° 低角度,色温再暖一档;调雾远距(110→90)让远处骑楼融进青灰;招牌/路灯材质给自发光色。以"石板路反光+招牌泛光"为验收意象。
3. **夜灯(P1)**:篝火加 Point Light(暖橙,强度 ~2,距离 ~8)+ 光强正弦抖动脚本;主路每根路灯顶部 Point Light(暖黄,只开 2-3 根最近的,其余靠 Bloom 假亮,控实时光源数)。
4. **昼夜切换(P1,可选)**:N 键两态切换(黄昏⇄夜),插值过渡 ~2s:平行光强度/角度/颜色、雾色(青灰⇄深蓝)、天空盒曝光、路灯开关。不做全天循环(超出 demo 范围)。
5. **打包前校验**:URP Asset 确认 HDR 开着(Bloom 依赖);Quality=PC High;跑一遍 FPS 记录(编辑器 Stats 截图存 `.codely/shots/`)。

## 验收标准
- [ ] Game 视图黄昏态:招牌/篝火有辉光,建筑转角有 AO 体积感,石板路可读(截图佐证)
- [ ] 夜态(若做):篝火/路灯照亮半径内 NPC 名牌与道路可辨认,无死黑区域
- [ ] 全套后效开启,烘焙三建筑+23 道具场景 FPS ≥ 30(编辑器 Stats)
- [ ] 无粉色材质/黑屏(自定义 Shader 红线:全部用 URP 内置)

## 已知边界/坑
- **禁自定义 Shader**:团结引擎 URP 对自定义 Pass 兼容差(黑屏判例),本任务只用内置 RendererFeature/内置光照。
- Renderer2D⇄UniversalRenderer 来回切换会黑屏——本项目已用 PC_High_Renderer,勿动默认渲染器。
- SSAO 是 RendererFeature 级开关,改完需重载域/重启才生效的可能;改前先 `manage_asset get_info` 读现状。
- 编辑器占用项目:全部走菜单/UNITY-TCP bridge,禁 batchmode;改完 File/Save。
